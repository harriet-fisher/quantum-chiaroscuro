Calibration

    

    
Labels drawn on the projector's own screen need no alignment (the shapes already sit where the light lands). After the projector has been bumped, or for a new position, re-align:

    

    
Four numbered markers are projected at the corners of the drawn shapes. Drag each marker (in the preview, or select it with 1-4 and nudge with the arrow keys, Shift for 10 px) until it sits on the same physical corner it was drawn on. The outline stretches with them. Apply saves calibration.json.

    

    
Safety margin

    
 projector pixels shaved off every lit region, so a small misalignment cannot light the glass. Every frame is also checked to be exactly 0 in the glass before it is sent.

Photographed glass-stays-black check

    
The software proves the glass pixels it sends are 0. Only a photograph shows whether the real glass stays dark. From a tripod, with the room dimmed and exposure and focus locked, photograph each of these and save into one folder:

    

      
→ black.jpg

      
→ white.jpg

      
→ dots.jpg (optional)

      

    

    
Then trace the real glass and panels on black.jpg with the pen tool (that trace is where the glass physically is, independent of the projector), and run:

    

    
Without the trace the verdict is NOT CHECKED: a check that cannot see misalignment does not get to call the glass safe.
